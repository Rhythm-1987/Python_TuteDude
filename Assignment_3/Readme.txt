TASK 1 – Recursive Factorial Program

This program calculates the factorial of a number using recursion.

The factorial of a number n is defined as:
n! = n × (n−1) × (n−2) × ... × 1

The program uses:
1. Base Case: When the number is 0 or 1, factorial is 1 and recursion stops.
2. Recursive Case: The function calls itself using the formula
   n! = n × (n−1)!

The user inputs a number and the program displays its factorial.

TASK 2 – Math Module Program

This program uses Python’s built-in math module to calculate mathematical values.

For the entered number, the program calculates:
Square root using math.sqrt()
Natural logarithm using math.log()
Sine value using math.sin()

Since square root and logarithm are only defined for positive numbers, the program asks the user to enter a positive value for those operations. The sine function works for all real numbers.
